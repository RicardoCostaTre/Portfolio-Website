# Portfolio Website

This repository is a **public-facing, versioned mirror** of my portfolio website.

The portfolio itself is actively developed and maintained in a separate **DevOps repository**. This repository exists primarily to provide a publicly accessible view of the project's source code and development history.

## Repository Purpose

- Provide a public version of the portfolio website source code
- Maintain visible version history for portfolio and recruitment purposes
- Showcase the structure, implementation, and technologies used in the project
- Live Site: https://www.ricardoct.co.za/

## Development

Active development does **not** take place directly in this repository.

The primary development repository is hosted in **DevOps**, where changes are developed, managed, and tested before relevant versions are reflected here.

As a result, this repository may not always contain the latest work-in-progress changes.

## Portfolio

This project contains the source code for my personal portfolio website, showcasing my software development experience, projects, and technical skills.
